## Estructura 
- Carpeta src: Están todos los scripts de python que se utilizaron para el proyecto
- Carpeta datos: Están todos los archivos generados de los scripts de python
- Carpeta zea_mays_GCF_902167145.1: La secuencia descargada de zea mays
- Carpeta oryza_sativa_GCF_034140825.1: La secuencia descargada de oryza sativa

## Ejecución 
Cada script se puede ejecutar por separado con el siguiente comando 

```
python3 archivo.py
```

Sin embargo es necesario poner todos los archivos de datos en la misma carpeta src pues para los procesamientos utiliza datos recopilados en estos archivos
